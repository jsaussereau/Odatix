---

Odatix has no hard-coded list of supported tools: a tool is a directory holding a
`tool.yml`, and a *flow* is one way of running it. Both are things you can add,
from the GUI or from a short YAML file.

{{< tutorial-cards >}}

> [!NOTE]
> Not a synthesis at all? A script, a training run, a benchmark — anything with
> no clock and no target — is a [workflow](/docs/features/workflows/), not a tool.

For the complete reference behind these two tutorials, see
[Custom tools and flows](/docs/custom_tools/).
