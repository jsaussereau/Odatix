# Odatix

> Odatix is a free and open-source design automation toolbox (Python, `pip install odatix`) for the implementation, validation and design space exploration of configurable digital designs. It generates every configuration of a parametrizable design (VHDL, Verilog, SystemVerilog, Chisel, HLS...), runs RTL analysis, synthesis, Fmax search, place & route and simulation jobs in parallel on the user's own EDA tools (Vivado, Quartus, Design Compiler, Genus, Innovus, Yosys + nextpnr, OpenLane, LibreLane, Verilator, GHDL, QuestaSim...), and gathers every metric in YAML result files shown by an interactive dashboard (Odatix Explorer).

EDA tools and their licences are not part of Odatix. A workspace is a directory initialized with `odatix init` (add `--examples` for ready-to-run example designs). AI agents should start with the guide for agents: it shows how to describe a design with the Python API (top level, clock, reset and parameters are detected from the sources) and how to run commands without a terminal (`-y -E`).
