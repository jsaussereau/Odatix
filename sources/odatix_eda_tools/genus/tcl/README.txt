Genus Tcl Scripts
=================

This directory contains the Tcl scripts and auxiliary files used to run
ASIC synthesis with Cadence Genus.

The scripts support both logical synthesis and physical synthesis flows.

Contents
--------

The main files in this directory are used to:

- Analyze and elaborate the RTL design.
- Run logical synthesis with Cadence Genus.
- Run physical synthesis using the Genus physical/iSpatial flow.
- Search for the maximum operating frequency (Fmax).
- Generate synthesis reports and implementation files.
- Prepare the synthesized design for visualization in Genus or Innovus.

Technology-specific setup files, such as timing libraries, LEF files,
QRC technology files, and MMMC configuration, are located in the
corresponding technology directories.
If you wanna add a new technology by yourself, you should create a new 
folder in genus/technology/


Visualizing a Synthesized Design
================================
After a synthesis has successfully completed, Odatix copies the Makefile
from this directory to the root directory of the synthesis job.

For example:
    work/fmax_synthesis/genus/<target>/<architecture>/<configuration>/

The resulting directory contains the synthesis results together with the
Makefile:
    <configuration>/
    |-- Makefile
    |-- timing_constraints.txt
    |-- rtl/
    |-- scripts/
    |-- report/
    |-- log/
    `-- ...

The Makefile provides commands to open the synthesized design with the
appropriate Cadence tool.

To use it, first go to the synthesis result directory:
    cd work/fmax_synthesis/genus/<target>/<architecture>/<configuration>

Then use the corresponding Makefile target to open the synthesized
circuit.

For example:
    > make genus

can be used to open the synthesized design in Cadence Genus.

For a physical synthesis, the generated Genus-to-Innovus handoff files
can also be used to visualize the physical implementation in Cadence
Innovus:
    > make innovus

This allows the user to inspect the synthesized circuit, including the
mapped standard cells and, for physical synthesis, the placement and
physical implementation of the design.


Notes
=====

By default, the physical synthesis flow allows you to visualize the design
after placement.
If you would also like to perform routing, run the following commands in
the Innovus console:
    > place_design
    > route_design
After routing is completed, you can inspect the routed design and generate
the different reports again to analyze timing, area, power, and other
physical implementation metrics.

The available visualization commands depend on the files generated by
the selected synthesis flow.

Logical synthesis produces a technology-mapped netlist and synthesis
reports, while physical synthesis additionally uses physical technology
information and generates the data required to inspect the physical
implementation.
